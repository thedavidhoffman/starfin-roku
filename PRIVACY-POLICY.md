# Privacy Policy

Starfin is an unofficial Roku client for connecting to a Jellyfin server that you provide.

## Data You Enter

Starfin accepts your Jellyfin server URL, username, and password so it can sign in to your server. It also supports Jellyfin Quick Connect and saved-account sign-in. Authentication information is sent only to the Jellyfin server URL that you configure.

You may optionally enter a TMDB API key to enable filmography information.

## Data Stored On Your Roku Device

Starfin stores information on your Roku device so you can keep your preferences and use saved accounts. Depending on the features you use, this can include Jellyfin server URLs, usernames, user IDs, authentication tokens, account image identifiers, application and account settings, and an optional TMDB API key.

Your Jellyfin password is not stored after authentication. Logging out removes the authentication token for the active account but does not remove unrelated saved accounts or settings. Forgetting a saved account removes that account's stored information. Using Reset Starfin clears Starfin's stored accounts, sessions, and settings from the Roku device.

## Data Sent To Your Jellyfin Server

Starfin communicates with your configured Jellyfin server to authenticate accounts; load libraries, movies, television, music, playlists, Live TV, photos, metadata, artwork, and playback information; and update favorites, watched state, playback sessions, and playback progress.

The Jellyfin server is operated by you or by whoever provides the server you choose to use. Data handled by that server is governed by the server operator's configuration and policies.

## Optional Metadata Services

When you use filmography enrichment, Starfin sends the TMDB API key you configured and a public person identifier to TMDB. When Starfin loads artist information, it may send public artist, entity, or page identifiers to MusicBrainz, Wikidata, and Wikipedia.

Starfin does not send your Jellyfin username, password, authentication token, or media library contents to these metadata providers. Information handled by each provider is subject to that provider's policies.

## Roku Performance Signals

Starfin sends Roku-defined performance beacons to the Roku operating system. These signals report timing milestones such as when the app becomes usable and when launch-blocking sign-in interaction begins or ends.

The beacons contain milestone names only. They do not contain credentials, media selections, user-interface content, or authentication results. Starfin does not operate its own analytics service.

## Diagnostics And Logs

Starfin writes diagnostic information to the Roku debug log while the app is running. Logs can include request URLs, item identifiers, status messages, cache details, playback details, and error information useful for troubleshooting.

These logs remain on your Roku device unless you or a developer with access to your Roku debugging session views or shares them.

## Advertising And Sale Of Information

Starfin does not sell personal information and does not use advertising trackers.
