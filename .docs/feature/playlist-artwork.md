# Playlist Artwork

Playlist cards and playlist contents use Poster artwork by default, consistent
with the other library artwork surfaces. The default applies to fresh settings
and after a settings reset. Existing saved artwork selections remain unchanged.

Users can independently select Poster, Thumbnail, Jumbo, or Detailed artwork
for playlist cards and playlist items in Artwork Settings. Thumbnail artwork
prefers `Thumb`, then `Backdrop`, then `Primary` when an earlier image type is
unavailable.
