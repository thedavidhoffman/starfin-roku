# Video Media Information

The movie/episode and playback toolbars open Media Info inside the shared [Media Options](media-options.md) dialog. Gold section headers and label/value rows replace the full-screen horizontal stream-card carousel.

Sections appear in source, video, audio, then subtitle order. Each stream gets a numbered section with its display title or a metadata summary. Source information includes the media title, container, file size, and path. The redundant source-name row is omitted. Stream rows retain resolution, frame rate, codec, profile, video range, bitrate, channel layout, language, and stream flags where available. Missing fields are omitted; unavailable source, stream, and subtitle information has explicit empty states. Long values wrap and expand their rows. Media information uses a 260-pixel label column and a 768-pixel value column, separated by 24 pixels. The centered Media Options dialog is 1,560 pixels wide and 940 pixels tall, with navigation to the left of the information pane. System Information retains its 1,536-pixel dialog and wider 530-pixel label column.

Up/Down scrolls the property sheet; holding either key repeats scrolling. The scrollbar indicates position. Left returns to category navigation. Back closes the dialog, applies pending options, and restores focus to the launching button. This is a read-only view of the first source, falling back to item-level streams when the source stream field is absent. The information pane itself is read-only; other categories stage playback choices. During playback, additional sections show resolved stream and session diagnostics.

`MediaOptionsDialog` extends `Dialog`; its content mounts `VideoMediaInfoContent` in the Media Info pane. Movie, TVEpisode, and VideoPlayer use the `mediaOptions` OverlayHost request and their owned commit handlers. `VideoMediaInfoContent` owns media formatting. The shared `SectionedInformation` control owns section rendering, wrapping, scrolling, and scroll timers; SystemInformationContent uses it too and retains ownership of system-data collection. Updating sections resets scrolling and stops held-key timers.

Rooibos suites cover data formatting, dialog lifecycle, rendering, scrolling, empty states, and the toolbar close/focus path. The Media Options RTA scenario captures both toolbar layouts and exercises deferred choices, a playback-mode restart, and pause restoration.
